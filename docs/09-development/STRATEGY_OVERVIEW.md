## Target Markets

### Primary Markets
1. **Performance-Critical Games** - Competitive multiplayer, VR, fighting games
2. **Linux-First Developers** - Open source projects, Steam Deck exclusives
3. **Live Service Games** - MMOs, battle royale, F2P games
4. **Indie Success Stories** - Games that blow up and need optimization

### Market Size
- Total addressable market: ~2,000 Linux games/year
- Serviceable addressable market: ~850 performance-critical games/year
- Serviceable obtainable market: 100 games/year (Year 2 target)

### Why as high as 40%?
- Real technical advantage (measurable 1000x improvement)
- Open source momentum (proven model)
- Growing market (Steam Deck, cloud gaming)
- No direct competitors (we're first)
- Professional execution capability
